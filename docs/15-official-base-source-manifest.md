# 基礎版官方資料來源 Manifest

## 範圍與限制

此 manifest 只採用 [《冒險少女公會》官方網站](https://www.paintcanfarm.com/aggboardgames/zh) 上可直接讀取的文字、官方規則書、官方 FAQ 與勘誤。repository 不下載、嵌入、辨識或提交官方圖片、掃描檔、卡面及美術；因此網站上僅以圖片呈現的卡片列表與規則書，不能作為本次可寫入的卡牌數值來源。

機器可驗證資料位於 `packages/content-base/src/sources/official-base-source-manifest.ts`。驗證器會要求每一個已確認欄位都有 HTTPS 官方來源與定位，每一個未確認欄位都有缺口原因。

## 不可自行推測與啟用規則

- 本次沒有啟用任何官方基礎版卡牌；`base:demo` 依然是原創示範 Content Pack。
- 任何未有文字／合法可定位規則書來源的名稱、份數、費用、戰力、榮譽與效果，必須保持 `todo`／`disabled`。
- 卡片列表或規則書「存在」不等於其圖像內容已被核對；這些資料不可由 OCR、人工看圖或相似卡推測補齊。

## 需要的合法官方來源

要完成完整 roster 與數值核對，仍需要可引用的官方文字卡表／規則書文字版，或你合法持有的規則書頁面（頁碼清楚、可供逐張人工核對）。最有價值的順序是：起始牌與設置頁、公開供應／魔物／魔王卡表頁、各卡數值與效果頁。取得後可把相應欄位由 `todo` 轉為 `verified`，但在此前不可啟用。
