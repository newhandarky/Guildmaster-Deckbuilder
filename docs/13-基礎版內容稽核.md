# 基礎版 Content Pack 資料校對

## 狀態

目前 `base:demo` 是引擎與 UI 用的原創示範資料，不是已校對的官方基礎卡表。所有示範卡在 `baseDemoAudit` 均標示為 `todo` 與 `disabled`，不得被宣稱或載入為正式基礎版資料。

## 啟用門檻

一張卡只有在下列資料都能由官方規則書、FAQ、勘誤或官方卡表定位確認時才可標示 `enabled`：

- 穩定 definition ID 與卡種
- 份數、費用、購買力、戰力與榮譽
- 效果與時序文字所對應的結構化欄位
- 每個已驗證欄位至少一個 HTTPS 官方來源與定位資訊

未確認資料一律保留 `todo` 或 `blocked`，並維持 `disabled`。不得以現有 MVP 示範數值、常見桌遊慣例或卡名推測補齊。

官方來源中的名稱只屬於 audit metadata，不能自動成為玩家 UI 的 display name。正式規則資料與 Presentation Pack 顯示資料分離；詳見 `20-呈現包規格.md`。

## 驗證

`validateContentAudit` 會拒絕未知來源、重複／缺少卡片盤點，以及含未驗證欄位卻標記為 `enabled` 的資料。內容測試位於 `packages/content-base/test/`。

候選資料的人工確認、正式 audit 升格與衝突退回流程見 [Content Verification 人工確認流程](./18-內容驗證審核流程.md)。
