# 基礎版起始內容候選盤點

## 狀態

這是 content audit 的候選層，不是正式 Content Pack。所有條目皆為 `needs-human-confirmation` 或 `todo`、`disabled`，且 `runtimeLoadable: false`；`base:demo` 不會讀取它們。沒有官方圖片、掃描、卡面或美術被加入 repository。

候選資料與驗證器位於 `packages/content-base/src/candidates/`。候選欄位不能轉換成 `verified`；必須先建立獨立的正式卡牌 definition、欄位級來源和 content audit，再依正式啟用門檻處理。已從使用者提供卡表頁人工讀出的機制候選、逐欄來源定位與缺口，見 [起始機制候選資料](./23-起始機制候選資料.md)；其內容仍是候選，不是正式卡牌資料。

候選 ID 使用中性機制 ID：`base:starter/adventurer-01` 至 `adventurer-05`、`base:starter/summoning-stone`、`base:starter/spirit-crystal`。官方人物名稱只保存在候選／audit 的來源 metadata；不得出現在 Card Definition ID、candidate ID 或 runtime ID。
