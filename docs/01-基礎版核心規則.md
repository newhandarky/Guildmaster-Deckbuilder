# 基礎版核心規則規格

本文件將官方基礎版說明書與網站勘誤整理成可測試的系統行為。卡片個別效果與一般規則衝突時，以卡片效果為優先。第一擴充規則另見 `10-第一擴充Vol1規則.md`。

## 1. 遊戲概況

- 玩家數：2–4 人
- 遊戲時間：約 45–75 分鐘
- 類型：牌庫構築、公開市場、隊伍位置管理
- 主要目標：取得卡牌與完成羈絆，累積最高榮譽值

## 2. 官方用語

| 官方名稱 | 程式內部可用 enum |
| --- | --- |
| 物資卡 | `material` |
| 魔物 | `monster` |
| 協助者 | `helper` |
| 道具 | `consumable` / `item` |
| 討伐階段 | `combat` |

玩家畫面、規則文字、測試名稱的中文描述與開發文件使用官方名稱；英文 enum 不直接顯示給玩家。

## 3. 基礎版內容物

| 類別 | 數量 |
| --- | ---: |
| 玩家起始牌組 | 4 組 |
| 每組起始牌組 | 5 張基礎冒險者、4 張召喚石、1 張精靈結晶、1 張回合與圖示對照卡 |
| 冒險者卡 | 60 |
| 物資卡 | 59 |
| 魔王卡 | 11 |
| 魔物卡 | 32 |
| 羈絆卡 | 30 |
| 協助者卡（進階） | 12 |

數位版不需要複製實體配件。內容驗證器應檢查目前 Content Pack 宣告的牌庫組成與重複數量是否自洽；物資與魔物的官方逐種類張數若無可稽核來源，保留為來源 metadata 缺口，但不再阻擋數位版規則、UI 或 playtest。未確認的張數不得標示為官方實體配比。

## 4. 遊戲設置

### 4.1 酒館公共區域

1. 洗混冒險者卡，建立冒險者牌庫；翻開 3 張形成招募區。
2. 洗混物資卡，建立物資牌庫；翻開 3 張形成商店。
3. 隨機抽取「玩家人數 + 2」張魔王卡，建立本局魔王牌庫並翻開第一張；其餘魔王本局不使用。
4. 洗混魔物卡，建立魔物牌庫；翻開 3 張形成魔物區。

### 4.2 玩家公會

1. 每位玩家取得 5 張基礎冒險者、4 張召喚石與 1 張精靈結晶。
2. 將 5 位基礎冒險者隨機排成面朝上的隊伍，位置由左至右為 1–5。
3. 每位玩家取得 7 張羈絆，選擇 5 張面朝上保留；其餘 2 張本局移除。
4. 4 張召喚石與 1 張精靈結晶成為起始手牌。
5. 最年輕玩家先手；數位版可提供隨機或手動指定，無須蒐集生日資料。

使用者提供的官方規則書視覺頁面（檔名 `page-05.jpg`、印刷頁碼 3、〈玩家設置〉第 1、2、4 點）**候選性地**列出起始 5 位冒險者為麥娜、慕莎、卡儂、修爾蒂與辛芙妮，各 1 張；並顯示它們先以面朝上隊伍成員進場，4 張召喚石與 1 張精靈結晶為起始手牌。這是規則規格核對與起始內容候選資訊，仍需欄位級來源與人工覆核；不得據此直接建立正式卡牌資料或標記 `verified`／`enabled`。

這是基礎 Rules Module 的官方起始配置，不可改成「所有起始牌洗入牌庫、第一回合抽 5 張」。若產品需要後者，只能採用獨立、預設關閉且明示非官方的 [Starter Setup Policy](./21-起始設置政策.md)，不得覆寫 base Rules Module。

## 5. 卡牌概念

### 5.1 冒險者

- 職業分為近戰、坦克、遠程、法師、輔助。
- 主要欄位：名稱、招募費用、進入隊伍／在隊伍中的效果、戰力、榮譽值。
- 行動階段可從手牌將任意數量的冒險者加入隊伍。
- 參與討伐的冒險者及其裝備會置入棄牌堆；未參與者留在隊伍中。

### 5.2 物資

- 物資分為裝備與道具。
- 每位冒險者最多配戴 1 張裝備；換裝時原裝備立即置入棄牌堆。
- 使用道具後先留在玩家的遊戲區域，休息階段才置入棄牌堆。這是官方勘誤後的正確規則。

### 5.3 魔王與魔物

- 公開敵方卡具有討伐所需戰力、效果／報酬、購買力與榮譽值。
- 被討伐後先結算報酬，再進入討伐者的棄牌堆，之後可在購買階段提供購買力。
- 骷髏戰士共有 3 張；被討伐並結算獎勵後不進入玩家棄牌堆，而是放回魔物牌庫底部。此卡片效果優先於一般魔物目的地規則，使魔物區在每次完整 transaction 後始終維持 3 張。
- 魔王可能有特殊討伐規則；基礎版所有本局魔王被擊敗是遊戲結束條件之一。

### 5.4 羈絆

- 每位玩家本局固定 5 張，基礎規則下無法再獲得更多。
- 在遊戲過程中任意時間點達成條件時，將該羈絆翻至完成面。
- 完成全部 5 張會觸發遊戲結束；未完成羈絆不計分。

## 6. 回合順序

玩家依順時針輪流進行完整回合：

1. 行動階段一
2. 討伐階段
3. 行動階段二
4. 購買階段
5. 休息階段

休息完成後才切換至左手邊玩家。UI 可以讓玩家提早結束可選階段，但不得跳過必須結算的效果或選擇。

## 7. 個人牌庫抽牌與重建

這一節只適用於玩家自己的牌庫，不直接適用於冒險者、物資、魔物或魔王等公共供應牌庫。

### 7.1 抽牌途中重建

執行一次「抽 N 張」時依序抽取：

1. 若個人牌庫仍有牌，抽取牌庫頂 1 張。
2. 若個人牌庫已空、仍有尚未完成的抽牌數量，且棄牌堆有牌，才將棄牌堆洗混成新的個人牌庫並繼續抽。
3. 若個人牌庫與棄牌堆都無牌，只抽得到實際存在的張數。

因此，牌庫在完成最後一張抽牌後剛好變空，不會立即洗棄牌堆；必須等到之後仍需要繼續抽牌時才重建。

### 7.2 查看與展示

- 「查看牌庫頂」與「展示牌庫頂」不是抽牌。
- 查看／展示時牌庫為空或數量不足，不會洗混棄牌堆。
- 只查看／展示牌庫中實際剩餘的卡牌。
- 官方勘誤：冒險者「神樂」效果中的「查看」改為「展示」。

### 7.3 公共供應牌庫耗盡

- 個人牌庫重建規則不得套用到公共供應牌庫。
- 冒險者或物資供應牌庫因實際補列抽取而變成空牌庫時，引擎必須產生正式的 `SUPPLY_DECK_DEPLETED` 遊戲事件，記錄原因、時點與觸發 command；已經為空且沒有抽取時不得重複產生。
- 專案負責人於 2026-07-31 核准基礎版數位處理：耗盡不是額外結束條件，也不凍結後續 command；公開列只保留並處理實際存在的卡片。
- 冒險者牌庫耗盡且沒有可補卡片時，招募區可以少於 3 張或為空；空狀態顯示「目前沒有冒險者可以雇用」。
- 物資牌庫耗盡且沒有可補卡片時，商店可以少於 3 張或為空；空狀態顯示「目前沒有道具、裝備可以販售」。
- 魔物供應不存在耗盡分支，也不產生 `SUPPLY_DECK_DEPLETED`。3 張骷髏戰士被討伐後回到魔物牌庫底部，並在同一完整 transaction 內補列，使所有 committed state、Snapshot、Replay 與 PlayerView 的魔物區始終正好 3 張。
- 不得因耗盡建立虛擬卡、洗玩家棄牌堆或自行觸發究極魔神。啟用 Vol.1 時，仍由 Vol.1 Rules Module 監聽事件並套用其已確認的究極魔神登場規則。
- 以上是已核准的專案規則，不宣稱為官方規則原文。

## 8. 行動階段

玩家可依任意順序、任意次數執行下列合法行動。

### 8.1 加入冒險者

- 從手牌將冒險者放到隊伍最右側。
- 基礎 Rules Module 提供的隊伍人數上限為 5；這不是引擎常數，其他卡牌或 Rules Module 可以改變上限。
- 若加入前已達目前上限，先將位置 1 的冒險者及其裝備置入棄牌堆，其餘依序左移，新冒險者進入最右側。

### 8.2 配戴裝備

- 從手牌將裝備配戴於一名冒險者。
- 每名冒險者上限 1 件裝備。
- 已有裝備時，新裝備取代舊裝備，舊裝備立即置入棄牌堆。

### 8.3 使用道具

- 從手牌使用道具並結算效果。
- 卡片暫時留在玩家的遊戲區域，休息階段統一置入棄牌堆。

### 8.4 移除遊戲

效果若要求移除卡片，該卡離開本局，不進棄牌堆，也不再參與計分。

## 9. 討伐階段

1. 選擇 1 張公開魔王或魔物作為討伐目標。
2. 自隊伍位置 1 起依序累加戰力，直到總和第一次達到或超過目標戰力。
3. 若合法擊敗目標，將這些冒險者及其裝備置入棄牌堆。
4. 立即處理擊敗報酬與觸發效果。
5. 將被擊敗的敵方卡放入玩家棄牌堆，除非卡片效果另有指示。
6. 隊伍仍有成員且可合法擊敗其他目標時，可再次討伐；玩家也可以主動停止。

### 9.1 討伐不變條件

- 戰力足夠後不得為了棄牌或觸發效果而額外派遣後方冒險者。
- 超出的戰力不保留到下一次討伐。
- 敵方效果可限制參與人數、職業或結算方式，並優先於一般流程。
- 討伐階段結束時觸發的卡片，通常必須當下仍在隊伍中；卡片若另有文字則依卡片。
- 「加入隊伍時，此回合中……」類效果一旦建立，即使來源稍後離開隊伍，仍持續到本回合結束。

## 10. 購買階段與購買力

### 10.1 購買力來源

購買階段的可用金錢由下列來源相加：

1. 仍在手牌中的每張召喚石：印刷購買力 1。
2. 仍在手牌中的精靈結晶：印刷購買力 1。
3. 仍在手牌中的每張魔王／魔物卡：使用卡片左下角印刷的購買力。
4. 本回合討伐報酬取得、且可在本購買階段使用的金錢。
5. 其他卡片或 Rules Module 明確提供的購買力／金錢修正。

只有購買階段開始時仍在手牌、且具有購買力的卡片才列入手牌來源；已進入隊伍、配戴、使用、棄置或移除的卡不會因原本在手牌而重複計算。

官方範例：2 張召喚石各提供 1，加上 1 張購買力 2 的食人魔，共 4；再加上本回合討伐魔王取得的 6 金錢，合計 10。

### 10.2 購買

1. 展示所有用來提供購買力的手牌並計算總額。
2. 玩家可招募／購買任意張公開冒險者與物資，只要總費用不超過可用金錢。
3. 新取得卡片放入棄牌堆。
4. 每回合最多一次，玩家可將 1 張任意手牌置入棄牌堆，選擇招募區或商店任意數量的公開卡洗回各自牌庫，再抽取並展示相同數量。

購買力是回合中的暫時資源。引擎應分開記錄印刷購買力、討伐報酬、效果修正、費用修正與已花費數值，避免把暫時金錢永久寫回卡片。

補充：刷新公開列是「招募區或商店」二擇一的每回合一次行動；玩家棄 1 張任意手牌後，所選公開列可同時洗回任意數量的卡，再從其對應供應牌庫展示相同數量。不得把此行動拆成兩個公開列各一次。

## 11. 休息階段

依序執行：

1. 將招募區、商店與魔物區各補至 3 張；若本回合擊敗了公開魔王，翻開下一張魔王。
2. 將剩餘手牌與玩家遊戲區域中使用過的道具置入棄牌堆。
3. 抽 5 張作為下一回合手牌；抽牌途中依第 7 節處理個人牌庫重建。
4. 檢查尚未完成的強制效果與遊戲結束事件後，將回合交給下一位玩家。

冒險者／物資供應無法補足時，只處理實際存在的卡片並發出一次耗盡事件。魔物的循環目的地與補列則在同一 transaction 完成，魔物區不得提交少於 3 張的狀態。基礎 Rules Module 依第 7.3 節的核准規則繼續遊戲；UI 顯示冒險者／物資空狀態，不自行重建牌庫或推導其他結果。Vol.1 Rules Module 可覆加其已確認的究極魔神登場規則。

## 12. 遊戲結束與計分

### 12.1 觸發條件

基礎版符合任一條件即觸發遊戲結束：

- 本局所有魔王均被擊敗。
- 任一玩家完成自己的 5 張羈絆。

### 12.2 完成當前輪次

觸發後仍完成目前輪次，直到起始玩家右手邊的玩家完成回合。該輪已經行動過的玩家不會再多進行一回合。

### 12.3 基礎榮譽計分範圍

每位玩家只計算自己公會內的牌：

- 個人牌庫
- 手牌
- 棄牌堆
- 隊伍中的冒險者
- 隊伍中配戴的裝備
- 玩家遊戲區域中尚未於休息階段棄置的道具
- 已完成的羈絆卡

上述區域中的冒險者、物資、魔王與魔物依卡面榮譽值計分；已完成羈絆依卡面計分。未完成羈絆、公共供應區卡片、其他玩家公會內的牌與移除遊戲的牌不計入該玩家分數。

最高分獲勝。平手依序比較：

1. 擊敗的魔王數量
2. 擊敗的魔物數量
3. 仍相同則共同獲勝

## 13. 進階規則（選用）

### 13.1 協助者

- 協助者是對所有玩家生效的中立角色。
- 設置時抽取與本局魔王數量相同的協助者，洗混後翻開 1 張。
- 每擊敗 1 名魔王，移除目前協助者並翻開下一張。
- 數位版 provisional playtest 目前只啟用候選協助者 08：在場時所有玩家隊伍上限為 6；離場後若隊伍超過 5 人，依座位順序將各玩家最右側的超額冒險者及其裝備放入該玩家棄牌堆。
- 裝備的 `event-after` trigger 固定先於 Rules Module lifecycle hook，因此先結算擊敗目標觸發的裝備效果，再輪替協助者與收斂隊伍容量。
- 其餘 11 張候選協助者目前只參與抽選、揭示與輪替，個別效果仍停用。

### 13.2 羈絆輪抽

每位玩家先取得 5 張羈絆，選 1 張保留，其餘向右傳；重複直到各有 5 張。

進階規則並不改變基礎設置中的「每位玩家最終擁有 5 張羈絆」；它只改變取得這 5 張羈絆時的選擇流程。

## 14. 官方勘誤與 FAQ 回歸清單

- 物資簡介勘誤：道具使用後暫留玩家遊戲區域，休息階段才置入棄牌堆。
- 神樂：效果文字的「查看」改為「展示」。
- 巴風特：用於擊敗它的冒險者洗回冒險者牌庫；基礎冒險者改為移除遊戲，但抽取的新冒險者數量不變。
- 奇美拉：被擊敗後，其配戴的魔物移除遊戲。
- 修爾蒂：位置 1 的加成不套用自己，但其他同名卡可以適用。
- 討伐階段結束時效果只由當下仍在隊伍中的來源觸發，除非文字另有說明。
- 一旦戰力已足夠，不可再額外派遣冒險者。
- 「加入隊伍時，此回合中」效果在來源離隊後仍持續。
- 巫妖：若支付隊伍與裝備後仍無法捨棄必要的手牌冒險者，巫妖留在公共區域且不取得報酬。
- 查看／展示牌庫頂不會重建個人牌庫；只有抽牌途中需要繼續抽而牌庫已空時才會洗混棄牌堆。
