# 卡片圖片文字資料索引

本目錄將使用者提供的卡表圖片逐張整理成可搜尋的 Markdown 文字。每一張來源圖片對應一個檔案；卡片編號依圖片由左至右、由上至下排列。

## 轉錄原則

- `卡面文字`會把圖示展開成中文，並統一空格與標點，方便搜尋；因此不是排版逐字複製。
- `狀態：已辨識`表示圖面足以辨認欄位，不代表效果已在遊戲 Engine 實作。
- `狀態：待確認`表示圖示、數值或時序仍有歧義；不自行猜測。
- 張數若只能由整體卡表或專案測試配置推定，會明確標示，避免誤稱為官方逐種類張數。
- 圖片本身不複製到 Repository；每份文件保留原始絕對路徑供人工覆核。
