# 基礎版已驗證卡牌盤點

## 覆蓋狀態

此盤點目前是 **incomplete**。官方網站可直接讀取的 Q&A 文字已確認 4 張卡的名稱與卡種：神樂、巴風特、奇美拉、修爾蒂。這些條目均維持 `disabled`，因份數、完整數值與完整效果尚未由可定位的官方來源覆核。

現有 `base:demo` 18 張原創示範卡亦全部列入盤點，但標記為 `original-placeholder`、`todo`、`disabled`；它們不是官方卡表，也不能用於補齊官方資料。

## 優先順序

1. 起始牌：需取得可定位的官方來源後確認正式名稱、份數與購買力。
2. 常用公開供應：冒險者與物資，逐張建立名稱、份數、數值與效果來源。
3. 其餘基礎卡：魔物、魔王與特殊效果卡。

## 不可自行推測

卡片列表目前以官方網站圖片呈現；本 repository 不下載、不嵌入或使用官方圖片／卡面。未能從文字規則書、FAQ、勘誤或官方文字卡表確認的欄位必須維持 `todo`／`disabled`，不以圖片辨識、示範資料或桌遊慣例補值。
