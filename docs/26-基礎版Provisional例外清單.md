# 基礎版 Provisional 例外清單

只列出需要人工決策或更清楚合法資料的項目；不要求逐張逐欄確認。除非另註，候選資料都維持 `disabled`，不會載入正式 Content Pack。

## 已解除的 P0 例外

目前沒有因逐種類張數或基礎供應耗盡而保留的 P0 exception。

| 原例外 | 核准決定 | 後續邊界 |
| --- | --- | --- |
| 28 種物資與 14 種魔物的每種份數 | 專案負責人於 2026-07-31 決定逐種類張數不影響數位版開發、UI、規則或 playtest，不再列為 blocker。骷髏戰士另確認為 3 張。 | 官方來源仍只揭露物資總數 59、魔物總數 32；其他逐種類張數可維持未知 metadata，不得由總數反推或宣稱數位組成等同官方實體配比。 |
| 基礎供應牌庫耗盡後續 | 冒險者／物資公開列只處理實際存在卡片，可縮減至空並繼續遊戲；空列顯示核准訊息。骷髏戰士擊敗後回到魔物牌庫底，使魔物區 committed state 始終正好 3 張。 | `SUPPLY_DECK_DEPLETED` 只供冒險者／物資 audit／Rules Module 使用；魔物不產生耗盡事件或 pending ruling。Vol.1 仍可對前兩類事件套用其究極魔神登場規則。此為專案 policy，不冒充官方原文。 |

## 已確認／provisional 的其他資料

- 道具使用後暫留使用區至休息階段。
- 神樂「展示」牌庫頂。
- 巴風特：起始冒險者移出遊戲但抽取數不變。
- 奇美拉：擊敗後移除其配戴的魔物。
- 修爾蒂不對自身套用第一位加成。
- 骷髏戰士共有 3 張；擊敗並取得獎勵後回到魔物牌庫底部，不進玩家棄牌堆（數量由專案負責人確認，目的地依卡片效果）。
- 14 種魔物的擊敗獎勵、11 張魔王的效果、30 張羈絆的條件與榮譽、12 張協助者效果：已從使用者提供的清晰卡表逐張盤點為 `provisional`，但仍不會載入 production Content Pack。
- 30 張冒險者的職業圖示：已依規則書印刷頁 4 圖例映射為穩定 enum；六張先前文字不足的冒險者效果已補為 `provisional`（`medium` confidence）。

道具、神樂、巴風特、奇美拉與修爾蒂五項來自官方網站的 2025/9/1 Q&A／勘誤；骷髏戰士數量與基礎耗盡處理屬專案負責人核准資料／policy；其餘標為 `provisional` 的資料來自使用者合法提供、可定位的官方卡表視覺資料。三者不可混為相同證據等級。
