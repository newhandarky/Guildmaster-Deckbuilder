# 基礎版官方資料來源 Manifest

## 範圍與限制

此 manifest 採用 [《冒險少女公會》官方網站](https://www.paintcanfarm.com/aggboardgames/zh) 的文字、官方規則書、官方 FAQ 與勘誤。repository 不下載、嵌入或提交官方圖片、掃描檔、卡面及美術。

使用者已提供官方基礎規則書與卡表的本機視覺資料供 AI 視覺核對。這些影像可用來產生具頁碼／區域定位與 confidence 的 `provisional` 候選資料；不會保存到 repository，也不能直接將任何卡牌欄位標成正式 production 的 `verified`／`enabled`。現行狀態與人工例外流程以 [AI-first 驗證流程](./18-內容驗證審核流程.md) 為準。

機器可驗證資料位於 `packages/content-base/src/sources/official-base-source-manifest.ts`。驗證器會要求每一個已確認欄位都有 HTTPS 官方來源與定位，每一個未確認欄位都有缺口原因。

## 視覺來源與啟用規則

- 本次沒有啟用任何官方基礎版卡牌；`base:demo` 依然是原創示範 Content Pack。
- 任何未有文字／合法可定位規則書來源的名稱、份數、費用、戰力、榮譽與效果，必須保持 `todo`／`disabled`。
- 不得把視覺頁面、卡片圖、官方美術或掃描檔提交到 repository。
- 規則書頁面的人工視覺核對，可用於更新規則規格與來源頁碼；不可將模糊、裁切不全或無法辨識的內容當作已確認事實。
- 卡片列表或規則書「存在」不等於所有逐張欄位都已完成稽核；任何缺少名稱、份數、費用、戰力、榮譽或效果證據的欄位仍必須保持 `todo`／`disabled`。
- 不能以相似卡、桌遊慣例或 `base:demo` 補齊缺失欄位；視覺來源上的候選讀值也必須記錄頁碼／區域並通過人工覆核後才能啟用。
