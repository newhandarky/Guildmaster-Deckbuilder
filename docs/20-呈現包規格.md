# Presentation Pack／Appearance Pack 規格

## 目的

Presentation Pack（亦可稱 Appearance Pack）只決定卡牌如何被玩家看見，不決定卡牌如何運作。它讓同一個穩定 Card Definition ID 可對應不同人物名稱、圖片與主題，且完全不改變規則結果。

## 身份與資料邊界

`CardDefinition.id` 是規則／效果／數值／卡片實例的唯一身份；存檔、Replay、AI、網路同步、合法性檢查與 Rules Module 都只能使用它。ID 必須是中性機制 ID，不得包含人物名稱、官方名稱、圖片檔名或顯示文案。人物名稱、圖片檔名、display text、locale 與 theme 不得作為任何遊戲邏輯 key，規則引擎也不得 import Presentation Pack 或 asset registry。

| 層 | 擁有內容 | 不得包含 |
| --- | --- | --- |
| Content Pack | stable ID、卡種、數值、效果、replacement、規則驗證 | 人物圖片、玩家名稱、主題／語系文案 |
| Presentation Pack | `definitionId` → display name、portrait/image asset key、簡短顯示文案、可選 variant/theme/locale | 效果、數值、Rules Module、Command handler、規則 ID 替換 |
| Source audit | 官方來源名稱、版本、頁碼／區域、確認狀態 | 直接供玩家顯示的文案或素材路徑 |

官方來源名稱可保留在 audit metadata，但不會自動成為 Presentation Pack 的 display name。若沒有 Presentation Pack，resolver 產生中性 placeholder 名稱與原創 placeholder 圖示 key。

## 概念 contract

未來實作時，Presentation Pack manifest 至少包含 `presentationPackId`、version、supported content definition IDs、theme、locale 與 hash。每個 entry 至少包含：

- `definitionId`（stable Card Definition ID）
- `displayName`
- `portraitAssetKey` 或 `imageAssetKey`
- `shortDisplayText`
- 可選 `variant`、`theme`、`locale`

`PresentationResolver.resolve(definitionId, preferences)` 回傳純 presentation view model。UI 只能消費此結果；React component 不得硬寫人物名稱、圖片路徑或自行選擇規則卡。多套 pack 對同一 `definitionId` 的輸出可以不同，但不得改變任一規則資料。

## Snapshot、Replay 與連線

- Snapshot／Replay 的規則重現只記錄 Content Pack／Rules Module versions 與 hashes。
- 若需重現視覺，可額外、非必要地記錄 Presentation Pack ID／version／hash。
- presentation 缺少或不相容時，以 fallback resolver 呈現，不能阻止舊 Snapshot／Replay 載入。
- 線上權威狀態、Command 與 Event 不傳遞圖片；各 client 可使用不同 Presentation Pack，且必須得到相同的規則結果。

## 資產與權利

不提交、嵌入或顯示官方圖片、卡面、美術或商標素材。Presentation asset 只接受原創、AI 生成或具有授權紀錄的素材。玩家顯示名稱與原始官方名稱分離，以便未來完全更換主題與世界觀。

## 後續實作 PR 與必測案例

本 PR 只提供文件與驗收條件。後續獨立 PR 應實作 presentation schema、resolver、原創 placeholder Presentation Pack 與 UI adapter，且不得改變遊戲玩法。

必測案例：

1. resolver 對不存在／不相容 pack 回傳中性 fallback。
2. 切換 pack、theme 或 locale 前後，GameState、合法 Command、AI 選擇與規則結果完全相同。
3. Presentation Pack 不可加入 effect、數值或重寫 stable definition ID。
4. Snapshot／Replay 缺少舊 presentation 時仍可使用 fallback 載入；content/rules hash 不相容仍維持既有錯誤。
5. 線上不同 client 選用不同 presentation pack，不影響權威 state 或 event payload。
